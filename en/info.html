Blåhaj Bot

your monitoring bot

It is a tool to help with server moderation, providing useful information and logs about users, join and leave logs, created invites... etc.

Invite Bot Support

What exactly does the bot do?

  • User Logs:

    Analyzes, approves, and monitors the full list of server members, extracting specific access data.

  • Advanced Moderation:

    From auto-roles, anti-links, text/photo-only channels to advanced logs, the bot allows you to automatically manage your server in the easiest and most efficient way.

  • Custom Configuration:

    It has countless configurable channels (logs, auto-roles, protections...) to fully secure the server.
