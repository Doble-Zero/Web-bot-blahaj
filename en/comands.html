Bot Commands

Explore the full list of moderation, configuration, and utility tools. Click on each block to see details, actions, and usage examples.

BOTConfig Channels Add media-only or text-only channels.

Example: /config_canales [action]

Options:

Actions
  • View configuration
  • Media only > Add channel
  • Media only > Remove channel
  • Text only > Add channel
  • Text only > Remove channel
BOTConfig Autoroles Automatically assign roles to users who message in a channel.

Example: /config_autoroles [status] [channel] [role]

Options:

Status
  • Enable
  • Disable
Channel
  • Select the channel to enable it on
Role
  • Role to assign
