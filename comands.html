Comandos del Bot

Automod

Gestiona los modulos para canales solo media / solo texto.

Uso: /config_canales [accion]

Autoroles

Asigna roles automaticamente a los usuarios que entran al servidor.

Uso: /config_autoroles [estado] [canal] [rol]

Logs

Configura el envío de registros sobre distintas acciones del servidor.

Uso: /config_logs [evento] [estado] [canal]

Protecciones

Gestiona los modulos del automod para el servidor.

Uso: /config_protecciones [estado]

Invite

Genera una invitación manual para el bot.

Uso: /invite

Invite Info

Muestra las personas invitadas por un usuario.

Uso: /invites [user]

Utilidad

Muestra el estado interno del bot y la latencia actual.

Uso: /ping

Sistema

Recarga un modulo del bot (solo para el creador o Dueño).

Uso: /reload [nombre]

Info

Muestra el progreso y las actualizaciones recientes del bot.

Uso: /roadmap

IA

Genera un resumen del chat de un canal en un rango de tiempo usando la IA.

Uso: /resumen [canal] [tiempo]
